# البحث العميق — HAI_SERCH

تطبيق بحث طويل المدى يعمل من السحابة ويزامن نفس المهام والنتائج بين Android وWindows.

## الهدف

- إدخال نص، صورة، أو فيديو.
- استمرار البحث حتى بعد إغلاق الأجهزة.
- جمع نتائج موثقة وترتيبها حسب المطابقة.
- مزامنة الطابور والمهمات السابقة والنتائج بين Android وWindows.
- VPN / Egress داخل السيرفر فقط.
- تشغيل شخصي بتكلفة أساسية 0 قدر الإمكان.

## دورة حياة الصورة والفيديو

1. يرفع المرفق إلى السحابة ويرتبط بالمهمة.
2. يظل موجودًا طوال البحث، حتى لو استمر ساعات أو أيام.
3. عند اكتمال البحث تبقى المهمة والمرفق والنتائج في **المهمات السابقة** السحابية، ويمكن فتحها من Android أو Windows المرتبطين بنفس الحساب.
4. يمكن اختيار **استمرار البحث** لنفس المهمة مع نفس المرفق والنتائج السابقة.
5. عند اختيار **أرشفة** من جهاز معين، ينزل التطبيق نسخة كاملة إلى تخزين ذلك الجهاز: المرفق + النتائج + المصادر. أرشيف Android مستقل عن أرشيف Windows ولا تتم مزامنته.
6. حذف عنصر من شاشة الأرشيف يحذف النسخة المحلية لذلك العنصر فقط بعد تأكيد المستخدم، ولا يحذف المهمة السحابية.
7. المرفق السحابي يحذف عند إلغاء المهمة أو حذف المهمة السحابية نهائيًا.
8. إطارات الفيديو وملفات التحليل المشتقة تبقى مؤقتة وتحذف آليًا بعد انتهاء الحاجة إليها.

## الطابور

- حد أقصى 5 مهام غير منتهية لكل حساب.
- مهمة واحدة فقط تعمل في الوقت نفسه.
- بقية المهام تنتظر بنظام FIFO وتبدأ تلقائيًا بعد انتهاء السابقة.

## البنية المختارة

- **Client:** Flutter (Android + Windows من قاعدة كود واحدة)
- **API:** FastAPI / Python
- **Database + queue:** PostgreSQL فقط، لتجنب Redis وخدمة إضافية
- **Search:** SearXNG + HTTP crawler خفيف، وPlaywright عند الحاجة فقط
- **Media:** FFmpeg + OCR + Whisper.cpp عند الحاجة
- **Notifications:** Firebase Cloud Messaging
- **Server:** Oracle Cloud Always Free Ampere A1
- **VPN:** WireGuard داخل السيرفر
- **Updates:** GitHub Releases

## فلسفة استهلاك المجاني

1. لا يتم تشغيل المتصفح الكامل إلا للمواقع التي تحتاج JavaScript.
2. لا يتم تحليل الفيديو إطارًا بإطار؛ تستخرج لقطات رئيسية فقط.
3. نتائج البحث والصفحات لها cache لمنع إعادة العمل.
4. المهام تستخدم PostgreSQL queue بدل تشغيل Redis منفصل.
5. ملفات التحليل المؤقتة فقط تخضع للتنظيف الآلي؛ مرفقات المهمات السابقة لا تحذف زمنيًا.
6. نماذج الذكاء محلية وخفيفة/quantized ولا تعتمد على API مدفوع.
7. لكل مهمة ميزانية موارد قابلة للضبط، مع إمكانية البحث الطويل دون هدر CPU.
