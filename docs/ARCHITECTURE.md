# معمارية البحث العميق

## المسار

```text
Android / Windows (Flutter)
        |
        v
    FastAPI
        |
        +---- PostgreSQL (الحسابات/المهام/النتائج + Queue)
        |
        +---- /data/uploads (مرفقات المهمات السحابية)
        +---- /data/tmp     (تحليل مؤقت فقط)
        |
        v
 Research Worker
        |
        +---- SearXNG
        +---- HTTP fetch + Trafilatura
        +---- FFmpeg / OCR عند الوسائط
        |
        v
 WireGuard / Egress على نفس السيرفر
        |
        v
      Internet
```

## سياسة الوسائط

1. الصورة أو الفيديو يرفع إلى مساحة الحساب في `/data/uploads` ويرتبط بالمهمة.
2. يبقى المرفق موجودًا أثناء البحث وبعد اكتماله ضمن **المهمات السابقة** حتى يمكن فتح نفس المهمة من Android أو Windows.
3. الملفات المشتقة مثل keyframes وملفات التحليل تستخدم `/data/tmp` فقط وتحذف آليًا.
4. endpoint المرفق محمي بنفس Device Token ولا يسمح لجهاز من حساب مختلف بتنزيل الملف.
5. عند أرشفة المهمة على جهاز، ينزل التطبيق المرفق مباشرة إلى أرشيف ذلك الجهاز مع Snapshot من النتائج والمصادر.
6. الأرشيف المحلي غير متزامن: Android وWindows لكل منهما مجلد أرشيف مستقل.
7. حذف عنصر من الأرشيف يحذف مجلد ذلك العنصر المحلي فقط.
8. إلغاء المهمة أو حذف المهمة السحابية هو ما يحذف المرفق من السحابة.

## الطابور

كل حساب يملك حتى 5 مهام غير منتهية. يعمل Worker على مهمة واحدة فقط وبترتيب FIFO؛ المهمة التالية لا تبدأ حتى تتحرر المهمة السابقة. البحث الطويل ينفذ على جولات مع backoff لتقليل استهلاك CPU.

## استمرار البحث

المهمة المكتملة أو الجزئية يمكن إعادتها إلى الطابور من «المهمات السابقة». تبقى نتائجها الحالية والمرفق نفسه، وتبدأ جولات إضافية لإيجاد أدلة أو نتائج أفضل.

## لماذا PostgreSQL Queue؟

لتوفير خدمة وذاكرة إضافية. الأقفال والمعاملات في PostgreSQL تمنع تجاوز سعة الطابور وتضمن أن Worker واحد فقط يطالب بالمهمة التالية. للاستخدام الشخصي لا نحتاج Redis في البداية.

## VPN

الـVPN داخل السيرفر وليس الجهاز. WireGuard يطبق على مستوى Linux أو Network Namespace. التطبيق لا يحصل على مفاتيح VPN. `EGRESS_PROXY_URL` مخصص لوضع متقدم يكون فيه VPN في namespace/gateway منفصل ويصل إليه الـWorker عبر proxy.

## Android + Windows

نفس Flutter client ونفس الحساب السحابي للمهمات والطابور والنتائج. ربط الأجهزة يتم برمز مؤقت. الأرشيف المحلي وحده لا يدخل في المزامنة.
