# ميزانية التشغيل المجاني

> القيم أدناه مبنية على صفحات المزودين الرسمية المتاحة في سبتمبر 2026، وقد تتغير لاحقًا. راجع الأسعار قبل النشر.

## Oracle Cloud Always Free — الأساس

الاختيار الأساسي هو VM.Standard.A1.Flex ضمن Always Free. وثائق Oracle الحالية تذكر ما يعادل **2 OCPU و12 GB RAM** شهريًا ضمن 1,500 OCPU-hour و9,000 GB-hour، إضافة إلى **200 GB Block Volume إجماليًا** للحساب (يشمل boot volumes).

الاستخدام المقترح على VM واحدة:

- نظام التشغيل والخدمات: ~1–2 GB RAM
- PostgreSQL: 256–512 MB في الاستخدام الشخصي
- SearXNG: حد 768 MB
- FastAPI: حد 512 MB
- Worker: حد 3 GB
- الباقي cache للنظام وتحليل الوسائط المؤقت

الرابط الرسمي:
- https://docs.oracle.com/en-us/iaas/Content/FreeTier/freetier_topic-Always_Free_Resources.htm

## التخزين

النسخة الأساسية تستخدم Oracle Block Volume. الصور والفيديو المرتبطة بالمهمات **تبقى في السحابة بعد انتهاء البحث** حتى تظهر بنفس المهمة في Android وWindows ويمكن أرشفتها من أي جهاز مرتبط.

لا يوجد حذف زمني تلقائي لمرفقات `/data/uploads`. الحذف يحصل فقط عند إلغاء المهمة أو حذف المهمة السحابية نهائيًا. الذي يخضع للتنظيف الزمني هو `/data/tmp` فقط (keyframes وملفات التحليل المشتقة).

للاستخدام الشخصي، يفضل مراقبة المساحة وإظهار استخدامها في الإعدادات لاحقًا. إذا اقتربت مساحة Oracle من حد مريح يمكن نقل المرفقات إلى Cloudflare R2؛ Free Tier الحالي يتضمن 10 GB-month مع egress مجاني للـStandard storage.

- https://developers.cloudflare.com/r2/pricing/

## قواعد تمنع استنزاف المجاني

1. حد الطابور **5 مهام** لكل حساب، لكن **مهمة واحدة فقط تعمل فعليًا في الوقت نفسه**.
2. كل جولة تتحقق من 40 صفحة فقط ثم تتوقف وتعيد المهمة للطابور إذا لزم.
3. أقصى مرشحين للجولة 250، لكن الجولة الأولى تبدأ أقل وتتوسع تدريجيًا.
4. HTTP أولًا؛ Browser automation ليس المسار الافتراضي.
5. الفيديو لا يحلل frame-by-frame؛ الحد المخطط 12 keyframes.
6. ملفات التحليل المؤقتة فقط تنظف آليًا؛ مرفقات المهمات السابقة لا تحذف بمرور الوقت.
7. لا يوجد API ذكاء مدفوع ضمن المسار الأساسي.
8. لا يوجد Redis أو Elasticsearch في النسخة الشخصية.
9. المهام غير المكتملة تستخدم backoff بالدقائق بدل استهلاك CPU باستمرار.
10. الحد الافتراضي للنتيجة 10 عناصر.

## النتيجة العملية

هذه البنية مصممة للاستخدام الشخصي وعدد مهام محدود، وليس كخدمة عامة لآلاف المستخدمين. المورد الأهم أثناء البحث هو CPU، وبعد اعتماد «المهمات السابقة» يصبح التخزين موردًا ثانيًا مهمًا. لذلك يبقى التنفيذ المتوازي = مهمة واحدة، بينما يسمح الطابور بحفظ حتى خمس طلبات، وتظل مرفقات المهمات السابقة سحابية إلى أن يقرر المستخدم حذفها.
